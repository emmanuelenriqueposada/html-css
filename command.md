**Iniciando repositorio usamos**
git init

**Verificar estado de los archivos usamos**
git status
git status -s

**Agregando archivos al repositorio usamos**
git add
git add .
git add --all

**Agreagmos los cambios al repositorio local y comentario del cambio usamos**
git commit -m <comentario>

**Verificando el repositorio usamos**
git remote -v
git remote add origin <enlacederepositorio>

**Subir el repositorio usamos**
git push origin <ramaprincipal>
